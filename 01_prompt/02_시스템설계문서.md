# 시스템 설계 문서

## 1. 문제 정의

프로젝트 진행 중 일정 변경이나 마감 기한 연장이 필요한 경우, 외부 협력사에게 정중하고 전문적인 이메일을 작성해야 한다.

기존에는 담당자가 상황에 맞는 표현을 직접 작성하고 수정하는 과정에서 시간이 소요되며, 이메일의 형식과 표현 품질이 담당자마다 달라질 수 있다.

본 프로젝트에서는 생성형 AI를 활용하여 프로젝트 일정 변경 요청 이메일 작성 업무를 자동화하고, 일정한 품질의 업무 이메일을 생성하는 것을 목표로 한다.

---

# 2. 타겟 사용자

## 주요 사용자

- 프로젝트 담당자
- 업무 협업 담당자
- 외부 커뮤니케이션 담당자

## 사용 목적

외부 협력사 및 관계자에게 일정 변경, 협조 요청, 업무 안내 등의 이메일을 빠르고 전문적으로 작성하기 위해 사용한다.

---

# 3. 업무 과업 정의

## 과업명

프로젝트 마감 기한 연장 요청 이메일 작성

## 목표

- 변경 일정 안내
- 지연 사유 전달
- 상대방에 대한 사과 및 협조 요청
- 전문적인 비즈니스 이메일 생성

---

# 4. 입력 데이터 형태

AI에게 제공하는 입력 정보

| 항목 | 내용 |
|---|---|
| 목적 | 이메일 작성 목적 |
| 대상 | 이메일 수신자 정보 |
| 핵심 내용 | 전달해야 할 주요 내용 |
| 필수 포함 항목 | 반드시 포함해야 하는 정보 |
| 톤 | 원하는 문체 및 분위기 |

---

```text
[업무 요청: 메일 초안 작성]

(메일 작성 목적 입력)

(받는 사람 및 관계 입력)

- 변경 사유:

- 반드시 포함해야 할 내용 입력
